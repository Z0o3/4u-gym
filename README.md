# 4u-gym

Sitio web de 4U Wellness Gym construido con Next.js, React y TypeScript.

## Requisitos

- Node.js 20.9 o posterior
- npm

## Desarrollo local

```bash
npm install
npm run dev
```

Abre `http://localhost:3000` en el navegador.

## Compilación

```bash
npm run build
npm run start
```

## Publicar en Vercel

1. Sube la carpeta completa a un repositorio de GitHub.
2. En Vercel selecciona **Add New → Project**.
3. Importa el repositorio `4u-gym`.
4. Confirma **Framework Preset: Next.js**.
5. Deja **Root Directory** en `./`.
6. Deja **Output Directory** vacío.
7. Presiona **Deploy**.

Vercel detectará automáticamente el comando `next build`.
